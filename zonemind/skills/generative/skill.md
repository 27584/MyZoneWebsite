# 生成式模型（图片 / 视频生成）

本技能基于内置生成模型，按「次」固定费率扣 credits（生成成功后才计费），无本地密钥：

- **generate_image**：根据文字描述生成图片（文生图）。适合「帮我画一张 / 生成一张 / 做一张封面图」这类需求。
- **generate_video**：根据文字描述生成视频（文生视频）。生成通常需要 1~5 分钟。

执行纪律：
- 只有用户明确要求「生成图片 / 生成视频」时才调用对应工具；普通对话不要调用。
- 提示词要尽量详细具体（主体、风格、画面、细节），生成效果更好；不要替用户把含糊的需求加工成与意愿不符的内容。
- 未指定用哪个模型时，自动选用可用的文生图 / 文生视频模型；如需指定模型，在 `model` 参数里传模型名称。
- 两个工具都是**异步任务**：调用后立即返回「已提交」，不要等待或轮询；生成在后台进行，结果会作为单独的消息自动出现在对话里。你只需在提交成功后告知用户「任务已提交，完成后会自动显示在这里」，不要再声称「已完成」或编造结果地址。
